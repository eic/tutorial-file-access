## Glossary

EIC
: Electron-Ion Collider

DID
: Data Identifier - the `scope:name` used by Rucio to refer to a file, dataset or container

RECO
: Reconstructed output files (the output of the reconstruction, e.g. EICrecon)

FULL
: The full GEANT4 simulation output root files

EVGEN
: The input hepmc3 event generator datasets

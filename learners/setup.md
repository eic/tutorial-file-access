If you have not done so already, please follow the [setup instructions for Setting Up Your EIC Environment](https://eic.github.io/tutorial-setting-up-environment/setup.html) well before the start of the tutorial to ensure your system is ready.

This tutorial will go over how to browse and access simulation campaign files using rucio. We will also examine various use cases and how you might engage with the simulation output in each case. You will need a working eic-shell environment running for this tutorial.
